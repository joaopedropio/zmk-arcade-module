Pac-Man dongle configurator

Not connected.

Plug the dongle in over USB and press Connect. The page asks the firmware what settings it has, so it always matches whatever is flashed — nothing here is hard-coded. Changes are written to the dongle's flash as you make them and survive a power cycle. Needs firmware built with CONFIG_SHELL=y and a CDC ACM console, and a browser with WebSerial (Chrome, Edge or Opera on desktop).

Settings marked next boot are stored right away but only drawn after the dongle restarts. stored means flash has a value; anything else is what the firmware was built with.
